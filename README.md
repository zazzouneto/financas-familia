# Finanças Família

Controlo financeiro da família: resumo mensal, gráficos, orçamento por categoria e metas.
App em HTML/CSS/JS puro — funciona no GitHub Pages e pode ser instalado no telemóvel (PWA).

## Usar
1. Ative o GitHub Pages: *Settings → Pages → Branch `main` / root*.
2. Abra o site, entre (utilizador `admin`, senha `1234`) e troque a senha em **Dados**.
3. Em **Dados → Importar**, carregue o ficheiro `.json` com os seus lançamentos.

## Privacidade
Os dados ficam só no `localStorage` do navegador — nada é enviado nem guardado neste repositório.
Exporte uma cópia (JSON) com regularidade. O `.gitignore` impede o commit de ficheiros de dados.
